# Trackr mobile app

The Expo app lives in this folder. Start at `App.js` to see how the app state, actions, and main navigation fit together.

## Source layout

- `src/screens/` contains full-screen experiences, including the sign-in demo.
- `src/components/common.js` contains UI pieces shared across screens, such as application rows, status labels, and form fields.
- `src/theme/` contains the shared colors and the wrappers that apply dark mode and larger text.
- `src/data/applications.js` contains demo applications and date/label helpers.
- `src/styles.js` contains the visual styles used by screens and shared components.

The sign-in screen is a visual demo. Application data currently lives in app state and starts from the sample applications in `src/data/applications.js`.
